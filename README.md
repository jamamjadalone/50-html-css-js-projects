## 🚀 Getting Started

### Option 1: Clone the repository

```bash
git clone https://github.com/jamamjadalone/50-html-css-js-projects.git
cd 50-html-css-js-projects
```

### Option 2: Download as ZIP

1. Click the green **Code** button at the top of the repository.
2. Select **Download ZIP**.
3. Extract the ZIP file and open any project folder.

---

## 🛠️ How to Use

1. Open the project folder you want to explore (e.g., `27-drawing-app-javascript`).
2. Double-click `index.html` — it runs directly in your browser. No server needed.
3. For projects using external APIs (e.g., **GitHub Profile Search**), open the folder in VS Code and use [Live Server](https://marketplace.visualstudio.com/items?itemName=ritwickdey.LiveServer) for the best experience.

> 💡 **Tip:** Right-click the project's index.html and choose "Open with Live Server" inside VS Code for hot-reload while you code.
